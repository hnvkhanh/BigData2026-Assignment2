Assignment 2 database schema

Eight Parquet tables of GitHub activity. Arrows show links between activity tables; user and repository foreign keys are listed on each activity card.

Core lookup table Activity-table foreign-key reference PK = primary key · FK = foreign key

Joining

Join activity tables to Users on user_id (or the activity-specific user column), and to Repositories on repo_id. These numeric keys are row numbers for this release.

Stable user identity

Use github_user_id to match users across releases or to test_input.csv. Only rows with Users.is_cohort == True have complete activity histories.

Prediction-time cutoff

For a snapshot at time t, filter by row availability: first_seen_at for PRs, issues, and reviews; created_at for comments and pushes. Some status fields are populated later and can leak future information.
